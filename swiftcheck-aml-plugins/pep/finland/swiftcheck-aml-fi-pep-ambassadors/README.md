# fi_pep_ambassadors – chefs des missions diplomatiques finlandaises

Source : um.fi (ministère des Affaires étrangères) : liste des représentations par pays (consulats honoraires ignorés), missions permanentes, ambassadeurs itinérants, puis la fiche de contact de chaque représentation (rubrique « Personnel », titre « Head of Mission », « Consul General »…).

- Le robots.txt d'um.fi demande `Crawl-delay: 20` : le plugin ne descend jamais sous 20 s entre deux requêtes (le paramètre `delayMs` ne peut qu'augmenter ce délai). Une exécution complète dure environ 30 minutes.
- Paramètres : `delayMs` (≥ 20000), `maxMissions` (0 = toutes ; utile pour un essai).
- Pas de date de naissance publiée.
