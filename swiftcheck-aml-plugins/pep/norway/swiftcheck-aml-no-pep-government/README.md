# no_pep_government – gouvernement norvégien

Premier ministre et ministres en fonction (20), d'après l'API ouverte du Storting `https://data.stortinget.no/eksport/regjering`. Type PLUGIN_MANAGED ; paramètres : `apiUrl`, `delayMs`.
Pas d'historique ni de secrétaires d'État dans l'API. regjeringen.no n'est pas utilisé (Cloudflare).
