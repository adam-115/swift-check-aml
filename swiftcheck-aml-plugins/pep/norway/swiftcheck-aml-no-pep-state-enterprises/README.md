# no_pep_state_enterprises – entreprises d'État (Norvège)

Dirigeants (DAGL, LEDE, NEST, MEDL ; VARA si `includeAlternates=true`) des entreprises du secteur institutionnel 1120 et des statsforetak (forme SF), d'après le registre de Brønnøysund (https://data.brreg.no/enhetsregisteret/api).

- Type PLUGIN_MANAGED ; paramètres : `apiUrl`, `sectors`, `forms`, `includeAlternates`, `delayMs`.
- Environ 728 entreprises, une requête de rôles chacune (~6 min). Pas d'identifiant de personne : nom + date de naissance.
