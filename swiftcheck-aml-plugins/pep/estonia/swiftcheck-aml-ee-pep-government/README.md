# ee_pep_government – Gouvernement (Estonie)

Site officiel `https://valitsus.ee/en` : la page d'accueil liste le Premier ministre et les ministres, chaque fiche (`/en/prime-minister-ministers/...`) donne le nom, la fonction avec sa date de prise de fonction et la date de naissance.

- Membres en fonction uniquement : le site ne publie pas d'anciens ministres.
- Une page toutes les 2 secondes, User-Agent générique ; `robots.txt` sans délai imposé.
- Le président de la République (`president.ee`, protégé par Cloudflare) n'est pas lu par ce plugin.
