# lv_pep_institutions – Président, Cour suprême, Cour constitutionnelle, Banque de Lettonie

Cinq pages officielles, choisies par le paramètre `keys` :

- `president` : `president.lv/en/biography` (phrase « … became the President of Latvia on … ») ;
- `supreme-court-president` : `at.gov.lv/en/par-augstako-tiesu/struktura/vadiba` (« Since … the President of the Supreme Court has been … ») ;
- `senators` : `at.gov.lv/en/par-augstako-tiesu/senatori/departamentu-sastavs` (33 sénateurs des départements civil, pénal et administratif, dont les 3 présidents de département) ;
- `constitutional-court` : `satversmestiesa.lv/en/judges` (7 juges, président et vice-président) ;
- `bank-of-latvia` : `bank.lv/en/about-us/governance/structure` (conseil : gouverneur, 2 sous-gouverneurs, 3 membres).

- Les noms des sénateurs sont écrits « Prénom NOM » avec titres académiques : titres retirés, nom remis en casse normale (« KALNIŅŠ » → « Kalniņš »). Entités HTML (`&Scaron;`, `&scaron;`…) décodées.
- Ni naissance ni décès sur ces pages. Cour des comptes (`lrvk.gov.lv`) injoignable ; anciens présidents non lus.
- 2 secondes entre pages, User-Agent générique ; aucun des sites n'impose de délai.
